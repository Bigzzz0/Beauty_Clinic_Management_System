# 📑 คู่มือระบบการจัดการคลินิกความงาม (Beauty Clinic Management System)

ยินดีต้อนรับสู่ระบบการจัดการคลินิกความงาม (Beauty Clinic Management System) เอกสารฉบับนี้เป็นคู่มือแบบละเอียดสำหรับการติดตั้ง การดูแลระบบความปลอดภัย และการใช้งานระบบสำหรับผู้ใช้ทั่วไป เพื่อความถูกต้องในการส่งมอบโครงการที่เป็นมืออาชีพ

---

## 🛠️ ส่วนที่ 1: รายละเอียดโครงสร้างเทคโนโลยี (Tech Stack)

* **Framework**: Next.js 15+ (App Router) ด้วย React 19 และ TypeScript
* **Database**: MySQL 8.0+ จัดการ Schema และคิวรีผ่าน **Prisma ORM**
* **State Management**: Zustand (เช่น `auth-store` และ `cart-store`)
* **Styling & Icons**: Tailwind CSS 4.0+, Shadcn UI Components และ Lucide Icons
* **Security & Auth**: JWT Authentication และระบบควบคุมสิทธิ์ตามหน้าที่งาน **Role-Based Access Control (RBAC)**
* **Scheduling & Daemon Check**: React hooks loops และ Web Audio Synthesizer

## 📥 ส่วนที่ 2: คู่มือการติดตั้งและการเริ่มใช้งาน (Developer & Admin Installation Guide)

### 1. ความต้องการของระบบ (Prerequisites)
* Node.js เวอร์ชัน 20.0.0 หรือสูงกว่า
* MySQL Server เวอร์ชัน 8.0 หรือสูงกว่า
* เครื่องมือจัดการแพ็กเกจ `npm` (ติดตั้งมาพร้อม Node.js)

### 3. การติดตั้งโค้ดและไลบรารี
```bash
# คัดลอกโครงการ (Clone Repository)
git clone https://github.com/Bigzzz0/Beauty_Clinic_Management_System.git
cd Beauty_Clinic_Management_System/nextjs-app

# ติดตั้งแพ็กเกจไลบรารีทั้งหมด
npm install
```

### 3. การกำหนดค่าสภาพแวดล้อม (.env Configuration)
คัดลอกไฟล์ต้นแบบสภาพแวดล้อม:
```bash
cp .env.example .env
```
เปิดไฟล์ `.env` และกำหนดค่าตัวแปรสำคัญดังต่อไปนี้:

| ตัวแปร | คำอธิบาย | ตัวอย่างการตั้งค่า |
| :--- | :--- | :--- |
| `DATABASE_URL` | ลิงก์เชื่อมต่อฐานข้อมูล MySQL สำหรับ Prisma | `mysql://root:password@127.0.0.1:3306/beauty_clinic_db` |
| `JWT_SECRET` | คีย์ลับสำหรับสร้างและตรวจสอบความปลอดภัยโทเค็นล็อกอิน | `your-super-secret-jwt-key-change-this` |
| `DB_BACKUP_USER` | ชื่อผู้ใช้ MySQL สำหรับระบบสำรองข้อมูลอัตโนมัติ | `root` |
| `DB_BACKUP_PASSWORD` | รหัสผ่าน MySQL สำหรับการสำรองข้อมูล (จำเป็นต้องกรอก) | `your_mysql_root_password` |
| `DB_NAME` | ชื่อฐานข้อมูลในการรันและสำรองข้อมูล | `beauty_clinic_db` |
| `BACKUP_ENCRYPTION_KEY` | คีย์ความลับสำหรับเข้ารหัสไฟล์สำรองข้อมูล (AES-256) | `your-secure-backup-encryption-key` |

### 4. การจัดการโครงสร้างฐานข้อมูล (Database Migrations)
```bash
# รันการสร้างตารางและดึงข้อมูลเริ่มต้น (Database Schema & Seed)
npx prisma migrate dev
npx prisma db seed
```

### 5. การรันระบบในเครื่องโลคัล (Local Development)
```bash
# รันพัฒนาเพื่อเข้าทดสอบโค้ด
npm run dev
```
เปิดเบราว์เซอร์และเข้าไปยัง [http://localhost:3000](http://localhost:3000)

## 🔒 ส่วนที่ 3: ระบบสำรองความปลอดภัยและการกู้คืนข้อมูล (Database Backup & Disaster Recovery)

ระบบความปลอดภัยข้อมูลถูกออกแบบด้วยการสำรองไฟล์บีบอัด เข้ารหัสระดับทหาร และทำความสะอาดคราบร่องรอยการโจมตีอัตโนมัติ

### 1. การทำงานของระบบสำรองข้อมูล (`scripts/backup_db.js`)
* **บีบอัดข้อมูล (Gzip)**: บีบอัดข้อมูลแบบกูบิเปิลเพื่อย่อไฟล์ให้เล็กที่สุด
* **เข้ารหัสหนาแน่น (AES-256-CBC)**: เข้ารหัสผ่านรหัสผ่าน `BACKUP_ENCRYPTION_KEY` โดยแฮชผ่าน SHA-256 เพื่อความปลอดภัยและเพิ่ม Random 16-byte IV ด้านหน้าไฟล์
* **ลบข้อมูลชั่วคราว (Secure Cleanup)**: ล้างไฟล์ SQL ที่เป็นข้อความปกติทิ้งทันทีหลังรันสำเร็จ
* **หมุนเวียนไฟล์เก่า (Automatic Rotation)**: เก็บไฟล์สำรองย้อนหลัง 14 วัน และทำการลบไฟล์เก่ากว่านั้นอัตโนมัติ

#### วิธีรันสำรองข้อมูลด้วยตนเอง:
```bash
node scripts/backup_db.js
```
*ไฟล์จะถูกจัดเก็บอย่างปลอดภัยในโฟลเดอร์ `/nextjs-app/backups` ในรูปแบบไฟล์ `.sql.gz.enc`*

#### การตั้งค่ารันอัตโนมัติทุกเที่ยงคืน (Unix Cron):
```bash
0 0 * * * node /path/to/nextjs-app/scripts/backup_db.js >> /var/log/clinic-backup.log 2>&1
```

### 2. การกู้คืนข้อมูล (Database Decryption & Restore)
หากต้องการกู้คืนฐานข้อมูลจากไฟล์เข้ารหัสลับ ให้ดำเนินการตาม 2 ขั้นตอนนี้:

#### ขั้นตอนที่ 1: ถอดรหัสไฟล์สำรองข้อมูลคืนเป็นไฟล์ SQL ปกติ
```bash
# กำหนด BACKUP_ENCRYPTION_KEY ให้ตรงกับรหัสตอนสำรองข้อมูล
# รันสคริปต์ถอดรหัส (ส่งพารามิเตอร์พาธไฟล์สำรอง)
node scripts/decrypt_backup.js backups/beauty_clinic_db-backup-[timestamp].sql.gz.enc
```
*ผลลัพธ์: จะได้ไฟล์ถอดรหัส `.sql` กลับมาในโฟลเดอร์ backups*

#### ขั้นตอนที่ 2: นำข้อมูลกลับเข้าสู่ MySQL
```bash
mysql -h 127.0.0.1 -u root -p beauty_clinic_db < backups/beauty_clinic_db-backup-[timestamp].sql
```

## 💻 ส่วนที่ 4: คู่มือการปฏิบัติงานสำหรับบุคลากรคลินิก (Detailed User Manual)

เอกสารส่วนนี้จัดทำขึ้นสำหรับเจ้าหน้าที่ผู้ใช้งานในคลินิกประจำวัน เพื่อเป็นแนวทางในการปฏิบัติตามมาตรฐานการบริการ (Standard Operating Procedures - SOP)

### 1. แดชบอร์ดวิเคราะห์ผลแบบเรียลไทม์ (Intelligent Dashboard Navigation & Upcoming Alerts)
หน้าแดชบอร์ดทำหน้าที่เป็น "ศูนย์ควบคุมหลัก" ของคลินิก ออกแบบมาเพื่อเน้นการนำทางที่รวดเร็วและการเฝ้าระวังคนไข้:
* **การนำทางด้วยการคลิกกล่องตัวเลขสถิติ (Stat Cards Linkage)**:
  * **กล่องจำนวนคนไข้ใหม่**: คลิกเพื่อข้ามไปหน้า `"ทะเบียนคนไข้"` (`/patients`) ทันทีเพื่อลงทะเบียนคนใหม่
  * **กล่องยอดธุรกรรมการชำระเงิน**: คลิกเพื่อข้ามไปหน้า `"ประวัติการขายและบิล"` (`/transactions`) เพื่อตรวจบิลค้างจ่าย
  * **กล่องสินค้าคงคลังคงเหลือ**: คลิกเพื่อข้ามไปหน้า `"รายงานคลังสินค้า"` (`/inventory`) เพื่อเช็กรายการสินค้าใกล้หมด
  * **กล่องยอดขายและรายงานประสิทธิภาพ**: คลิกเพื่อข้ามไปหน้า `"รายงานภาพรวม"` (`/reports`) เพื่อเปิดดูรายงานค่าคอมมิชชันและยอดขายสะสม
* **กลไกสัญญาณเตือนคิวเร่งด่วนคนไข้ (Upcoming Appointment Alerts)**:
  * ทุกๆ นัดหมายที่มีคิวเข้าบริการในอีก 30 นาทีข้างหน้าและมีสถานะเป็น `"นัดหมายแล้ว" (SCHEDULED)` จะได้รับการตรวจสอบโดยระบบส่วนหน้าโดยอัตโนมัติ
  * เคสนัดด่วนเหล่านี้จะแสดงเส้นขอบกล่องตารางเวลาเป็น **สีเหลืองอำพันเงางาม** พร้อมมี **ไฟกระพริบอนิเมชันสีส้ม (Pulse Badge)** กะพริบอยู่ข้างชื่อคนไข้เสมอ เพื่อเตือนให้พนักงานต้อนรับรีบจัดเตรียมแฟ้มประวัติ และจัดห้องทรีทเมนต์ไว้รอคนไข้ล่วงหน้า

### 2. ขั้นตอนการขายและระบบแคชเชียร์ POS (Cashier POS System & Preset Buttons)
ระบบจุดชำระเงิน (POS) ออกแบบมาให้ทำงานร่วมกับข้อมูลคนไข้และประวัติคอร์สได้อย่างลื่นไหล ป้องกันการกรอกตัวเลขผิดพลาด:
1. **การสร้างบิลขาย (Add to Cart)**: เลือกรายชื่อคนไข้จากระบบค้าข้อมูล → ค้นหาสินค้าหรือคอร์สทรีทเมนต์ที่ต้องการขาย → กดปุ่มบวกเพื่อเพิ่มลงตะกร้าสินค้า
2. **การสั่งซื้อชำระเงิน (Checkout Dialog)**: เมื่อกดปุ่มชำระยอดรวม ระบบจะเปิดกล่องการชำระเงิน (Payment Dialog) ขึ้นมา
3. **การใช้ปุ่มรับเงินสดด่วน (Preset Numpad Presets)**:
   * ใต้ช่องระบุจำนวนเงินสดรับ จะมีปุ่มทางเลือกด่วน ได้แก่ `100`, `500`, `1,000`, `2,000`, `5,000` บาท
   * เมื่อคลิกปุ่ม ตัวเลขจำนวนเงินสดจะถูกป้อนเข้าสู่ช่องกรอกทันทีโดยแคชเชียร์ไม่ต้องพิมพ์เลขเอง ช่วยเพิ่มความเร็วในช่วงเวลาที่มีลูกค้าต่อคิวชำระเงินหนาแน่น
4. **การทอนเงินที่ถูกต้อง (Automatic Change Calculation)**:
   * หากรับเงินสดเข้ามามากกว่ายอดสุทธิในบิล ระบบจะแสดง **ยอดเงินทอน (Change Due)** บนกล่องข้อความเป็นสีเขียวโดดเด่นสะดุดตา เพื่อป้องกันความสับสนและปัญหาสรุปยอดแคชเชียร์ไม่ตรงหลังปิดร้าน

### 3. ระบบจัดการนัดหมายและการแจ้งเตือนจริง (Live Calendar Alerts & Permissions Toggle)
ระบบตารางเวลามาพร้อมความสามารถในการเตือนภัยล่วงหน้าแบบจริงจัง เพื่อไม่ให้พลาดนัดหมายสำคัญ:
* **การกรองสถานะนัดหมายด้วย Live Counts**:
  * แผงควบคุมด้านบนปุ่มนัดหมายมีปุ่มคัดแยกสี ได้แก่ **ทั้งหมด (All)**, **รอดำเนินการ (Scheduled)**, **เสร็จสิ้น (Completed)**, และ **ยกเลิก (Cancelled)**
  * แต่ละปุ่มจะคำนวณและแสดงตัวเลขจำนวนนัดหมายคงคลังของวันนั้นๆ แบบเรียลไทม์ ทำให้ผู้ดูแลสามารถวางแผนกำลังพลของหมอและพนักงานดูแลได้ตลอดทั้งวัน
* **ขั้นตอนการเปิด-ปิดระบบเตือนภัยจริงแบบเรียลไทม์ (Live Alerts Toggle Steps)**:
  * **ขั้นตอนที่ 1 (เปิดใช้งานครั้งแรก)**: คลิกปุ่ม `"🔔 เปิดระบบแจ้งเตือน"` ที่หัวตารางปุ่มขวา
  * **ขั้นตอนที่ 2 (ขอสิทธิ์เบราว์เซอร์)**: เบราว์เซอร์จะแสดงป๊อปอัปขออนุญาตส่งข้อความแจ้งเตือน (Notifications permission request) ให้กดปุ่ม **"Allow/อนุญาต"**
  * **ขั้นตอนที่ 3 (การยืนยันระบบ)**: ระบบจะส่งข้อความแจ้งเตือนจำลองความสำเร็จพุชเข้าหน้าจอคอมพิวเตอร์ของคุณ พร้อมเล่นสัญญาณเสียงชามม์คู่แสนเป็นมิตร และเปลี่ยนปุ่มที่หัวตารางเป็นสีเขียวระบุ `"ระบบเตือนทำงานอยู่"`
  * **การทำงานในฉากหลัง**: ทุกๆ 15 วินาที ระบบจะตรวจสอบนัดหมายคนไข้ของวันนี้ หากพบนัดหมายของคนไข้ท่านใดที่กำลังจะถึงกำหนดภายใน 30 นาทีข้างหน้า ระบบจะส่งการแจ้งเตือนพุชหน้าจอเบราว์เซอร์ (Desktop Push Notification) และเสียงแจ้งเตือนความถี่ดนตรีขึ้นมาทันที พร้อมแสดงแถบเตือน Toast ในแอปพลิเคชันที่มีปุ่ม `"ดูรายละเอียด"` เพื่อให้กดเปิด Modal ดูประวัติได้ทันที
  * **การปิดเตือนชั่วคราว (Toggle Off)**: หากไม่ต้องการรบกวนหรือใช้งาน สามารถกดปุ่มกระดิ่งสีเขียวเดิมได้ตลอดเวลา ระบบจะสลับสถานะเป็น `"ระบบเตือนถูกปิดอยู่"` ทันที (และจะจดจำค่านี้ไว้ในการใช้งานครั้งหน้าด้วย `localStorage`)

### 4. ขั้นตอนการตัดยอดคอร์สคนไข้ (Course Session Recoding Step-by-Step)
การบันทึกการใช้บริการคอร์สเดิมของคนไข้ มีระบบช่วยเหลือแบบแยกขั้นตอน เพื่อป้องกันการตัดจำนวนครั้งผิดพลาด:
* **ขั้นตอนการปฏิบัติ 3 ขั้นตอน (Three-Step Wizard)**:
  * **ขั้นตอนที่ 1 (เลือกลูกค้า)**: พิมพ์ค้นหาชื่อคนไข้ในช่องค้นหาด้านบน เมื่อพบชื่อแล้วให้คลิกเลือกลูกค้าคนนั้น ระบบจะซ่อนฟอร์มค้นหาและเปิดขั้นตอนการเลือกคอร์สถัดไปโดยอัตโนมัติ
  * **ขั้นตอนที่ 2 (เลือกคอร์สสะสม)**: ระบบจะแสดงรายการคอร์สทั้งหมดที่คนไข้ท่านนี้ได้ทำประวัติซื้อสะสมไว้ ในแต่ละการ์ดคอร์สจะมี **แถบประวัติคอร์สคงเหลือ (Progress Bars)** แสดงเปอร์เซ็นต์จำนวนครั้งที่ใช้ไปแล้วและจำนวนครั้งคงเหลืออย่างชัดเจน:
    * 🟢 **สีเขียว**: คอร์สคงเหลือมากกว่า 5 ครั้ง (การใช้งานปกติ)
    * 🟡 **สีเหลือง**: คอร์สคงเหลือน้อยกว่าหรือเท่ากับ 3 ครั้ง (สัญญาณเตือนความหมด)
    * 🔴 **สีแดง**: คอร์สคงเหลือ 1 ครั้งสุดท้าย หรือใช้หมดแล้ว (สัญญาณวิกฤต)
    * *คลิกที่การ์ดคอร์สเพื่อเลือกคอร์สที่จะใช้บริการในวันนี้*
  * **ขั้นตอนที่ 3 (บันทึกผู้ดูแลและการรักษา)**: เมื่อเลือกคอร์สแล้ว ระบบจะเปิดแบบฟอร์มให้ลงรายละเอียดการรักษา ได้แก่ แพทย์ผู้ดูแล, พนักงานบำบัดรักษา, ค่า DF/Hand Fee ที่เกิดขึ้น, และหมายเหตุบันทึกอาการการรักษาในรอบนี้ พร้อมแสดงข้อความสรุปยืนยันความถูกต้องทั้งหมดก่อนทำการกดยืนยันบันทึก

---

### 5. การจัดการหนี้ค้างชำระและการทวงถามอย่างสุภาพ (Debt Management & Aging Badges)
ระบบลูกหนี้มาพร้อมตัวช่วยคัดแยกเพื่อกำหนดเป้าหมายการทวงถามหนี้ตามความเร่งด่วน:
* **ตัวคัดกรองจัดลำดับความเร่งด่วน (Color-Coded Aging Badges)**:
  * 🟢 **หนี้ใหม่ (< 7 วัน)**: แสดงสถานะป้ายสีเขียว บ่งบอกว่าหนี้เกิดขึ้นไม่นาน สามารถพูดคุยติดตามในการนัดหมายรอบถัดไป
  * 🟡 **หนี้ค้างช่วงปกติ (7-30 วัน)**: แสดงสถานะป้ายสีเหลือง ควรเริ่มแจ้งเตือนความค้างชำระแก่คนไข้ผ่านโทรศัพท์หรือข้อความ
  * 🔴 **หนี้ค้างชำระนาน (> 30 วัน)**: แสดงสถานะป้ายสีแดงและมีการไฮไลต์เส้นขอบแถวสีแดงเข้ม เป็นกลุ่มลูกหนี้ที่ต้องให้ความสำคัญและจัดหาวิธีพูดคุยติดตามเร่งด่วนที่สุด
* **ปุ่มชำระด่วนประหยัดเวลา (Quick Pay Preset)**: ในป๊อปอัปชำระเงินของลูกหนี้ จะมีปุ่ม `"ชำระยอดทั้งหมด"` ซึ่งเมื่อคลิกแล้ว ระบบจะป้อนยอดหนี้คงเหลือทั้งหมดของคนไข้เข้าสู่แบบฟอร์มการรับชำระทันทีโดยพนักงานไม่ต้องพิมพ์เลขเอง ช่วยให้การรับชำระและตัดหนี้เสร็จสิ้นในคลิกเดียว

### 6. ตารางพนักงานยอดเยี่ยมเพื่อจูงใจทีมงาน (Consultant Performance & Trophy Icons)
ระบบกระดิ่งความขยันของทีมงานขายและที่ปรึกษา (Consultants) ได้รับการปรับปรุงเพื่อกระตุ้นเป้าหมายความสำเร็จของพนักงาน:
* **บอร์ดอันดับเกียรติยศสูงสุด 3 ตำแหน่ง (Leaderboard Highlight)**:
  * ในหน้ารายงานคะแนนความสามารถพนักงานขาย พนักงานที่ครองอันดับยอดขายยอดเยี่ยมสูงสุด 3 อันดับแรกประจำเดือน จะได้รับไอคอนถ้วยรางวัลทองคำ 🥇, เหรียญเงินเกียรติยศ 🥈, และเหรียญทองแดงแห่งความพยายาม 🥉 ตามลำดับ
  * มีการเน้นสีแถวรายการของยอดนักขายทั้งสามท่านเป็นสีเหลืองทองสง่างาม เพื่อสร้างบรรยากาศกระตุ้นเป้าหมายการขายที่ดีให้กับทีมงานในแต่ละเดือน

### 7. การดึงเอกสารข้อมูลนำออกระดับพรีเมียม (High-Fidelity CSV Data Exports)
ระบบรองรับการกดส่งออกรายงาน (Export CSV) ความละเอียดสูงในทุกหน้าสำคัญเพื่อความสะดวกของแผนกบัญชีและธุรการ:
* **ขั้นตอนการส่งออก**: คลิกปุ่ม `"Export CSV"` ที่หัวตารางรอประมาณ 1 วินาที ไฟล์จะดาวน์โหลดลงสู่เครื่องโดยอัตโนมัติ
* **มาตรฐานเอกสารพรีเมียม**:
  * **เปิดได้ทุกเครื่องสระไม่เพี้ยน**: ไฟล์เข้ารหัสภาษาไทยด้วยระบบ UTF-8 BOM ทำให้การเปิดไฟล์ใน Microsoft Excel, Google Sheets, หรือ LibreOffice บน Windows และ Mac แสดงอักษรไทยสระเอ สระแอ วรรณยุกต์สมบูรณ์แบบโดยไม่ต้องตั้งค่ารหัสตัวอักษรเพิ่มเติม
  * **ตารางสรุปหัวรายงาน (Metadata Summary Block)**: ทุกรายงานจะมีแถวบนสุดแสดงชื่อรายงาน, วันเวลาที่ดึงออก, ช่วงเวลาวันที่ฟิลเตอร์คัดเลือก และยอดรวมธุรกรรมทั้งหมด เพื่อใช้อ้างอิงการจัดทำเอกสารราชการหรืองานบัญชี
  * **พร้อมใช้งานคำนวณสูตร**: ข้อมูลเงิน ยอดขาย ค่าคอมมิชชัน และสินค้าคงคลัง ถูกจัดเก็บเป็นตัวเลขดิบ (Numeric formats) พนักงานบัญชีสามารถคลุมดำเพื่อใช้สูตร `=SUM()` หรือ `=AVERAGE()` บน Excel ได้ทันทีโดยไม่ต้องทำการแปลงค่าข้อความเป็นตัวเลขก่อน

## 🛡️ ส่วนที่ 5: สิทธิ์ความปลอดภัยระดับองค์กร (System Access Security & RBAC)

ระบบกำหนดให้สิทธิ์ความปลอดภัยในแต่ละตำแหน่งงานแยกจากกันอย่างเด็ดขาด ผ่าน Middleware ตรวจสอบ JWT:

* 🔐 **Admin (ผู้ดูแลระบบ)**: เข้าถึงได้ทุกฟังก์ชัน เมนูการเงิน ธุรกรรม คลังสินค้า รายงาน และระบบรันสำรองข้อมูล API
* 🩺 **Doctor (แพทย์)**: เข้าถึงตารางนัดหมาย ประวัติการรักษาของคนไข้ บันทึกการทำบริการของแพทย์ และอัตราค่าตอบแทนแพทย์ (DF)
* 💆 **Therapist (พนักงานทรีทเมนต์)**: เข้าถึงตารางนัดหมาย บันทึกการรับบริการ และข้อมูลค่าตอบแทนพนักงาน (Hand Fee)
* 💼 **Receptionist (ฝ่ายต้อนรับ/แคชเชียร์)**: เข้าถึงตารางนัดหมาย ทะเบียนข้อมูลคนไข้ ระบบแคชเชียร์ชำระเงิน POS และบันทึกคลังสินค้า
